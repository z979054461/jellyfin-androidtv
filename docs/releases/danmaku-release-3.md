# Jellyfin TV 定制版 3（正式签名）

基于官方 Android TV v0.19.10。这是个人定制客户端，不是 Jellyfin 官方发布。

## 新功能

- 播放控制栏增加“播放信息”：直接播放/封装转换/转码、容器、源视频/音频格式，以及播放器当前输入格式。播放不暂停，面板可用遥控器关闭；它不是网络测速，也不把压缩输入格式当作电视最终解码输出。
- 新安装的弹幕默认字号降至 80%，可选 50%–150%（每档 10%）。行数上限支持 1–20 的每个整数；实际可显示行数仍受屏幕、字号和字幕安全区域限制。已有字号/行数选择保留。
- 设置 → 关于增加检查更新入口。从本仓库查找匹配的发布包；由用户确认下载，再调用 Android 系统安装界面。不静默安装，不绕过电视的“允许安装未知应用”授权。
- 新版 Jellyfin 风格图标和电视横幅，不加入弹幕图案。

## 从预览版迁移（仅这一次）

本次改为真正的 release 构建，`debuggable=false`，并使用专用固定签名。

- 正式包名：`io.github.z979054461.jellyfin.danmaku`。
- 旧预览包名：`io.github.z979054461.jellyfin.danmaku.debug`。
- 两者可以并存，正式版第一次需要重新添加服务器、登录并设置偏好。**无需删除 Jellyfin 服务器、媒体库或服务器账号。**
- 以后正式版本保持包名和签名不变，可以使用应用内更新覆盖安装；签名或包名不一致的包会拒绝安装。
- APK 文件名为 `jellyfin-danmaku-191003.apk`，versionName 为 `0.19.10-danmaku.3`，versionCode 为 `191003`。

GitHub 暂标记为 prerelease 以留出真实电视验证时间，但 APK 是正式签名 release 构建，不是 debug 包。

## 更新安全与限制

更新源固定为本仓库 GitHub Releases，仅接受 HTTPS 和受限 GitHub 下载域名。下载前后限制大小，校验 GitHub 的 SHA-256、Android 包名、更大的版本号和当前安装签名。下载、检查或权限失败时不会影响正常播放。

首次安装此正式版本仍需手动下载；旧 debug 包不能直接覆盖升级为此正式包。应用内更新需要电视能访问 GitHub，并最终由用户在 Android 系统界面确认。当前没有下一个版本时会显示已经是最新版本。

## 验证范围

发布工作流对同一提交运行 release 构建、单元测试、独立弹幕核心与播放信息格式测试、detekt 和 Android lint，并验证 APK 签名、包名、版本和非调试标志后才发布。上游 lint/detekt 配置保留，运行成功不表示历史警告清零。

真实电视上的播放信息遥控器焦点、更新系统安装界面及不同服务器媒体流仍需要实际验证；未声称已完成全部电视兼容性测试。
