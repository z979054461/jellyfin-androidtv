## 发布边界

本次发布目标为 `v0.20.0-danmaku.1`，唯一附件为 `jellyfin-danmaku-200001.apk`。发布前先创建草稿并验证上传摘要，再公开；已有 tag 必须指向本次提交，已有附件必须与本次校验的 APK 摘要一致，否则停止，不覆盖或删除。签名 Secrets 不齐全时不创建 tag 或 Release。沿用原签名身份，临时密钥始终清理，不改旧版发行包，也不向 Release 上传校验和文件、密钥、配置或日志。
