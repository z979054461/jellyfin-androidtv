# Jellyfin TV 弹幕预览版 2

基于官方 Android TV v0.19.10 的个人增强版，不是 Jellyfin 官方发行版。

## 本次变化

- 弹幕按钮移到播放主控制栏，与字幕等操作放在一起。
- 未保存过开关设置时默认开启弹幕；此前明确关闭的设置仍然保留。
- 菜单显示加载状态与弹幕数量。空文件、404、401/403、网络错误、格式不支持和不可用播放流都有对应说明。
- 新增“重新加载弹幕”和服务端插件说明，不需要退出视频或来回开关。
- 暂停时调整透明度立即生效。
- 保留字号、行数、透明度、速度（显示时长）、时间偏移，以及暂停、拖动、续播和倍速同步。

## 使用

1. 安装下方 APK，应用名为 **Jellyfin Danmaku Debug**。
2. 登录自己的 Jellyfin，使用内置播放器播放点播视频。
3. 在播放控制栏选择弹幕图标，查看状态并调整设置。

服务端需要已经安装兼容的 [jellyfin-plugin-danmu](https://github.com/cxfksword/jellyfin-plugin-danmu)，并为本片准备匹配的 XML。客户端使用现有 Jellyfin 登录，读取服务端 `/api/danmu/{itemId}/raw` 接口，不会安装插件、修改服务端或搜索第三方弹幕站点。404 也可能只是本片缺少文件，不能据此判断插件一定没装。

## 安装与验证限制

- **调试预览包，非稳定发行版。** 旧版的常规播放已由用户报告在电视上可用；新版弹幕和遥控器交互仍需要真机验证。
- 包名保持 `io.github.z979054461.jellyfin.danmaku.debug`。CI 的调试签名可能与此前安装包不同，**不能保证直接覆盖升级**。如果安装提示签名冲突，请先保留旧包并记录登录/设置，再自行决定是否卸载该预览应用；不要卸载官方版或原 fengymi 客户端。卸载会清除本应用的本地登录和设置。
- 直播、外部播放器、不可拖动的播放流暂不支持弹幕。
- 发布工作流会先运行构建、测试、detekt 和 Android lint。上游的 lint/detekt 保留 ignore-failure 行为，任务通过不等于整个上游零警告。
- 不代表已完成真实 Jellyfin 插件、电视遥控器、HLS 转码或低性能设备兼容验证。
