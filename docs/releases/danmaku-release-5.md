# Jellyfin TV 定制版 5（更新页遥控与安装修复）

基于官方 Android TV v0.19.10。这是个人定制版，不是 Jellyfin 官方发布。

## 修复内容

- **下载完成后遥控器方向键没有反应。** 更新页此前异步完成时会删除并重建全部设置项，原下载按钮变为不可操作、取消按钮消失，却没有把焦点交给下一步。现在为动作设置稳定标识，并在列表重建完成后恢复到可操作项。任务执行中可聚焦取消，从安装器返回或启动失败后可聚焦“打开系统安装器”，取消/失败可继续重试。离开页面后取消焦点回调，避免旧任务抢占新页面焦点。
- **下载后直接打开系统安装器。** 点击下载后，成功下载并重新校验便打开 Android 系统安装器，最后一步仍由你确认；不再额外点一次安装。只对这次前台操作拉起一次，取消、离开页面或从安装器返回不会自动重复拉起。
- **系统安装器不再被权限设置入口挡住。** 已校验的 APK 保留“打开系统安装器”重试入口；“安装权限设置”独立列出。若厂商电视没有原生按应用设置页，仍可以显式尝试标准系统安装器，由系统决定是否允许以及要求何种确认。
- 若一种标准安装 Intent 没有处理器，会尝试另一种标准方式。系统安全拒绝不触发替代尝试，不绕过安装限制，也不改全局安全开关。区分校验失败、安装器不可用和系统阻止。
- 仅启动安装器失败时保留已下载、已校验 APK，不要求重新下载；每次真正启动前仍重新检查 SHA-256、包名、更高版本号和签名。没有新增安装权限，也没有第三方安装服务。

## 这次如何安装

版本 `0.19.10-danmaku.5`，versionCode `191005`，APK `jellyfin-danmaku-191005.apk`。正式包名、签名与第 3/4 版一致，可覆盖安装并保留数据，**不需要先卸载**。

如果旧版更新页已失去焦点，修复无法先在旧版里生效。这一次请用电视上原先能安装 APK 的文件管理器打开本版 APK 并确认覆盖安装；以后可使用修复后的更新页。应用仍然需要电视系统最终批准安装，不承诺所有 HyperOS 机型均可安装。
