# Jellyfin TV 定制版 4（正式签名）

基于官方 Android TV v0.19.10，不是 Jellyfin 官方发布。

## 这次更新

- **顶部加载网速**：呼出播放操作栏，头像左侧默认显示当前播放器实际收到的网络数据速率。约 2 秒滑动平均、每秒刷新，不是影片码率或网络带宽测试。操作栏隐藏就停止 UI 刷新，不发起额外测速请求。
- 区分等待数据、缓冲播放、暂停、空闲及本地播放。已有缓冲时 `0 B/s` 是正常情况；暂停后若播放器仍在预读，会如实显示数据。仅计播放器网络载荷（可能包括清单和外部字幕），不计本地/其他 App 流量、封面和弹幕请求。
- **按住临时 2×**：可定位点播播放中，长按播放/播放暂停键，看到 `2×` 提示后临时加速，松开恢复原速度。控制栏隐藏且没有菜单、节目表或跳过提示时，确认/Enter 也可触发。短按行为保留，不改保存的播放速度。失焦、暂停、切集或离开播放时自动恢复；为防遗漏松开事件，单次最长 30 秒。直播和不可定位流不启用。
- README 逐项整理相对官方的弹幕、播放信息、加载速度、临时倍速、更新、图标、包名/签名与 CI 差异。
- 去掉播放器输出完整媒体/字幕 URL 的日志，降低地址中凭据进入日志的风险。

## 安装与升级

- 版本 `0.19.10-danmaku.4`，versionCode `191004`，文件 `jellyfin-danmaku-191004.apk`。
- 正式包名和第 3 版保持一致：`io.github.z979054461.jellyfin.danmaku`；沿用相同签名，`debuggable=false`。
- 已安装正式第 3 版可在设置 → 关于检查更新，或用本次 APK 覆盖安装，**不需要先卸载**，应用数据会保留。安装仍需你在 Android 系统界面确认。
- 老 `.debug` 预览版与正式版是不同包，不能直接覆盖；首次使用正式版需登录服务器。无需删除服务器媒体库。
- GitHub 仍标记为 prerelease 留出真实电视验证时间，APK 本身是签名 release 构建。

## 验证范围

发布流程要求同一提交通过 release 构建、单元测试、独立弹幕核心/播放信息/更新/流量计量/状态显示/长按恢复回归、detekt 与 Android lint，并核验包名、递增版本及固定签名。保留上游 lint/detekt 对历史警告的处理方式，不把运行成功说成零警告。

尚未在真实电视验证第 4 版遥控器事件、顶部排版及不同媒体源兼容性；部分系统可能先拦截媒体键。请重点检查：短按暂停不变、长按和松开恢复、原速度为 1.5× 时恢复 1.5×、切集/按返回不残留 2×、菜单确认不误触发、播放/暂停时网速状态、连续显示隐藏操作栏。
